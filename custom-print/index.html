How the estimate works

This is a mesh-based estimate, not a slicer quote. An STL does not store print settings or units. Choose the correct units and infill; the estimate uses the closed mesh volume and approximate material density. Open, damaged, self-intersecting or unusually shaped meshes can make the estimate inaccurate. The final grams and time should be checked in a slicer before printing.

Pricing is read from the estimator settings.

The print assumptions are provisional and are read from the estimator settings.

Build volume is read from the printer settings. Measurements use the STL's current orientation; rotate the model in slicing software if needed.
